# Home Assistant Neptune Apex MonitorBrought to you by [Fullstack Systems](https://fullstacksystems.com).This custom integration pulls real-time probe data from a [Neptune Apex](https://www.neptunesystems.com/) and makes it available in Home Assistant as sensors, feed cycle controls, and diagnostics.![Apex dashboard in Home Assistant: feed cycle controls, water parameters with history, power, and inputs](https://raw.githubusercontent.com/denov/home-assistant-apex-neptune/main/docs/dashboard.png)## Features- Hardware, software, firmware info- Auto adds all probes and outlets  - Outles are currently read only - Diagnostic using amp and last power- Energy dashboard support via "Apex Total Energy"- Digital inputs (float, optical, leak switches) as binary sensors- Feed cycles: Feed A–D and Cancel Feed buttons, plus a Feed Mode sensor (Off/A–D, seconds remaining)  - The buttons need the Apex password in the integration settings- Reads the local status.json from the Apex controller (falls back to status.xml on older firmware)- Configurable F/C for temp- Works only on the local network- Designed for HACS install## Installation### Installation via HACS[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=denov&repository=home-assistant-apex-neptune&category=Integration)1.
