# Home Assistant Neptune Apex MonitorBrought to you by [Fullstack Systems](https://fullstacksystems.com).This custom integration pulls real-time probe data from a [Neptune Apex](https://www.neptunesystems.com/) and makes it available in Home Assistant as sensors, feed cycle controls, and diagnostics.![Apex dashboard in Home Assistant: feed cycle controls, water parameters with history, power, and inputs](https://raw.githubusercontent.com/denov/home-assistant-apex-neptune/main/docs/dashboard.png)## Features- Hardware, software, firmware info- Auto adds all probes and outlets  - Outles are currently read only - Diagnostic using amp and last power- Energy dashboard support via "Apex Total Energy"- Digital inputs (float, optical, leak switches) as binary sensors- Feed cycles: Feed A–D and Cancel Feed buttons, a Feed Mode sensor (Off/A–D), and a Feed Ends time  - The buttons need the Apex password in the integration settings- Reads the local status.json from the Apex controller (falls back to status.xml on older firmware)- Configurable F/C for temp- Works only on the local network- Designed for HACS install## Confirm before feedingIf a feed cycle runs an auto feeder (or anything else you don't want to trigger by accident), have the dashboard ask first.The integration can't do this itself: Home Assistant buttons have no confirmation of their own, so it's set on the dashboard card.In the dashboard editor, open the card and under **Interactions** set **Tap behavior** to *Perform action* → `button.press`with **Require confirmation** on. For a tile card, do the same for **Icon tap behavior**, since tapping the icon pressesthe button immediately otherwise. In YAML:```yamltype: tileentity: button.apex_feed_d   # use your entity IDtap_action: &feed_d  action: perform-action  perform_action: button.press  target:    entity_id: button.apex_feed_d  confirmation:    text: Start Feed D? This also runs the auto feeder.icon_tap_action: *feed_d```This only covers that card: the **Press** button in the entity's dialog, automations, and voice commands don't ask.## Installation### Installation via HACS[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=denov&repository=home-assistant-apex-neptune&category=Integration)1.
